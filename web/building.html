Compiling Lab Engine from Source

Compiling Lab CMAKE BUILD SYSTEM
CMake target-based configuration
Build System CMake 3.22+
Compilers MSVC 2022 (v143)
Clang 16+ / GCC 12+
C++ Standard ISO C++20 (/std:c++20)
Configurations Release / RelWithDebInfo / Debug
Game Target Lab.exe
Editor Target LabHammer.exe
Core Library LabEngineLib.lib
Operating System Windows 10/11 x64
Modular Target Build: CMakeLists.txt builds the shared static engine library LabEngineLib first. Both Lab.exe (the playable game) and LabHammer.exe (the 3D level editor) link against it, guaranteeing that changes to core rendering or physics compile incrementally and apply instantly to both executables.

1. System Requirements & Toolchain Prerequisites

Before compiling the engine and tools, ensure your environment meets the following baseline requirements:

  • Operating System: Windows 10 / Windows 11 (64-bit).
  • C++20 Compiler: Microsoft Visual Studio 2022 (MSVC v143, Version 17.4 or later) with Desktop C++ workload, LLVM Clang 16+, or MinGW GCC 12+.
  • CMake: Version 3.22 or newer (available in PATH).
  • Graphics Hardware: GPU with complete hardware support for OpenGL 4.5 Core Profile (NVIDIA GeForce GTX 900+, AMD Radeon R9 200+, or Intel UHD 620+).

2. Repository Hierarchy & Dependency Layout

The codebase is structured into clear module directories: 

Lab/
├── CMakeLists.txt        # Root build definition configuring all targets
├── include/              # Public engine headers (LabCore.h, LabRenderer.h, LabCombat.h)
├── src/                  # Implementation sources
│   ├── main.cpp          # Lab.exe entry point (Frozen-Life game client)
│   ├── editor_main.cpp   # LabHammer.exe entry point (3D level editor)
│   ├── LabCore.cpp       # Deterministic frame loop & window management
│   ├── LabRenderer.cpp   # OpenGL 4.5+ Direct State Access renderer
│   ├── LabCombat.cpp     # Slab raycasting, weapons, bot AI FSM
│   └── LabMap.cpp        # Plain-text .labmap parser & serializer
├── assets/
│   ├── maps/             # Plain-text .labmap level files
│   ├── textures/         # Bitmap textures (snow_frost, metal_hull, hazard)
│   └── models/           # 3D STL mesh assets
└── web/                  # Documentation portal (MediaWiki format)

3. Step-by-Step CMake Compilation (PowerShell)

Execute the following standard commands from a PowerShell terminal:

PowerShell – CMake Build Sequence 
# 1. Clone the repository
git clone https://github.com/YoungJasiek/Lab.git
cd Lab

# 2. Generate Visual Studio 2022 project solution
mkdir build
cd build
cmake .. -G "Visual Studio 17 2022" -A x64

# 3. Compile optimized Release binaries
cmake --build . --config Release --parallel

# 4. (Optional) Run automated verification suite
ctest -C Release --output-on-failure

4. Output Build Targets

Upon successful build, CMake outputs the following binaries under build/Release/:

Target Binary Type Description
LabEditor.exe Executable Unified Multi-Workspace IDE (3D Level, Tilemap, Character Studio, HUD Designer, Script IDE, Project Hub).
LabPlayer.exe Executable Standalone runtime client that loads and executes game projects via game.config.
LabServer.exe Executable Dedicated headless authoritative UDP multiplayer server (64-128Hz).
LabHammer.exe Executable Standalone 3D Level Editor CAD suite with Dear ImGui docking.
10 Modular DLLs Dynamic Libraries Decoupled subsystems: Engine.dll, render.dll, audio.dll, physics.dll, etc.
TestVerify.exe Test Suite Automated verification suite with 80 comprehensive tests (100% pass rate).

Decoupled Game Standalone Distribution

When shipping a game created with Lab, do not distribute the entire source repo or CMake project. Use the Standalone Exporter (Ctrl+B in LabEditor or via the Project Hub) to bundle a self-contained folder (e.g. games/frozen_life/demo/) containing LabPlayer.exe, the 10 DLLs, game.config, and the game's isolated assets/.

5. Running & Verifying Executables

Make sure working directory is either the project root or copies assets/ into the binary output folder: 

# Run the Frozen-Life game client
.\build\Release\Lab.exe

# Run the LabHammer 3D level editor
.\build\Release\LabHammer.exe

6. Troubleshooting Common Build Errors

Symptom / Error Message Probable Root Cause Resolution
fatal error C1083: Cannot open include file: 'glad/glad.h' Git submodules not cloned or GLAD header path missing in CMake. Run git submodule update --init --recursive from project root.
glCreateTextures: undefined symbol / nullptr function pointer GPU driver reports OpenGL version lower than 4.5. Update GPU driver to latest release; ensure dedicated GPU is selected over integrated graphics.
Failed to open assets/maps/cryo_outpost.labmap Process working directory not configured to project root. In Visual Studio Debugging properties, set Working Directory to $(SolutionDir)...
error C2039: 'span' is not a member of 'std' C++ language standard set below C++20. Verify CMake specifies target_compile_features(LabEngineLib PUBLIC cxx_std_20).

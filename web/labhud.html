Lab HUD (2D / HUD / GUI Editor)

1. Overview & Project Workflow

Lab HUD is a standalone visual 2D / HUD / GUI layout authoring tool for the Lab Engine. It allows designers to visually create, arrange, style, and script in-game HUD elements, tactical overlays, death screens, scoreboards, and interactive menus.

The editor follows the LabStudio dark industrial aesthetic (beveled panels, tactile buttons, sunken numeric sliders, and LabHammer toolbar icons).

Workflow: Startup Project Switcher (select Frozen-Life HUD or create a new project) → Interactive 2D Canvas Workspace → Save to human-readable .labhud format.

2. Canvas & Hierarchical Manipulation

  • Hierarchical Transforms: Root elements support 9-point responsive anchoring (TopLeft, Center, BottomRight, etc.) relative to the game viewport (e.g. 1920×1080). Child elements inherit their parent's coordinate space.
  • Smooth Dragging & Snapping: Move elements with grid snapping (10px default) or free precision movement.
  • 8-Point Bounding Box Resizing: Interactive resize handles on corners and edges for pixel-perfect adjustments.
  • Right-Click Context Menu: Fast actions at cursor position: Cut, Copy, Paste, Duplicate, Delete, Add Child Widget, Bring to Front, Send to Back, Edit Text, and Edit Lua.

3. Widget Library & Typography

Widget Type Category Description
CardPrimitivesBeveled translucent container card with customizable edge borders.
PanelPrimitivesHammer-style sunken or raised surface panel.
LabelTypographyHigh-readability text with live editing and font choice (GeoSans, System, DotMatrix).
HealthBarGame HUDSmooth horizontal progress bar with background channel and status fill.
AmmoCounterGame HUDTactical ammo clip/reserve counter with weapon designation tags.
CrosshairGame HUDVector dynamic reticle with center dot and precision cross lines.
ImageGraphicsCustom textured bitmap sprite supporting alpha transparency.
ButtonUIClickable tactical button with hover highlight and Lua click bindings.

4. Lua 5.4 Scripting & Data Binding

Every HUD element can be dynamically driven by Lua 5.4 game engine scripts.

  • Update Hook (luaOnUpdate): Executed every tick to synchronize values, colors, or visibility with the player state.
  • Click Hook (luaOnClick): Executed when the player clicks on an interactive HUD button or terminal widget.
  • Presets: Fast insertion of common game bindings:
    • Player:getHealth() • Player:getArmor()
    • Weapon:getAmmo() • Match:getTimer()
    • Player:respawn()

5. Custom Asset Browser & Import

Import custom bitmaps directly from disk using the built-in + IMPORT ASSET FROM DISK... dialog. Files are automatically copied into assets/hud_assets/, loaded into the OpenGL texture pipeline, and rendered as live thumbnails in the sidebar.

6. Plain-Text .labhud Serialization

Layouts are saved in a section-based human-readable token format identical to .labmap: 

LABHUD_VERSION 1

METADATA
    name "Frozen-Life HUD"
    author "Lab Team"
    resolution 1920 1080
END_METADATA

ASSETS
    asset custom_crosshair.bmp
END_ASSETS

ELEMENTS
    element health_card Card 40 -108 255 68 0.16 0.17 0.19 0.90 BottomLeft 0
        text ""
        font 2.0 0
        border 0.23 0.24 0.27 1.0 1.0
        texture ""
        binding ""
        lua_update ""
        lua_click ""
        children 2
        ...
END_ELEMENTS

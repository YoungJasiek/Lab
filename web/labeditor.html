1. Overview & Architectural Evolution

LabEditor is the primary development environment for the Lab Engine. Originally conceived as the classic CAD-styled LabHammer, the tool has been systematically transformed into a comprehensive, decoupled, multi-genre development suite. All hardcoded game references have been purged into separate script packages, establishing LabEditor as a universal creation tool for any 2D or 3D project.

2. The 5 Workspaces & 13 Specialized Sub-Modes

Accessible directly via View > Workspaces:

🏢 1. 3D Workspaces

  • Level & Geometry: CSG brush carving, plane slicing, lights, entity placements.
  • Animation 3D Timeline: Prop & model keyframe scrubbers.
  • Model Viewer: Turntable inspector, wireframe overlay, triangle counts.

🦾 2. LabStudio Integration

  • Weapon Grip Poser: Bone socket alignment for character rigs.
  • Reload Timeline: Multi-phase reload choreography curves.
  • Weapon Skins & Materials: PBR albedo, metallic, roughness.
  • Face Dialogue: Morph targets & audio viseme lip-sync.

🎨 3. 2D Workspaces

  • Level & Tilemap: Ortho grid, layered tile painting, Box2D physics.
  • 2D Animation: Spritesheet slicing & frame sequence player.
  • Multi-Genre HUD Canvas: Virtual 1920x1080 artboard designer.

📜 4. Scripting Workspaces

  • Code Editor IDE: Full-viewport interactive buffer with syntax highlighting.
  • Interactive Console: Real-time Lua REPL and engine debug log.

3. Play-In-Editor (PIE) Real-Time Simulation

Developers can simulate game mechanics directly inside the editor without restarting:

  • Play (F5): Starts fixed-timestep 64Hz physics, Lua updates, AI bot sensory loops, and dynamic vehicle suspension.
  • Pause (F6): Freezes simulation time while leaving the free-flight camera active for deep inspection of rigid bodies and collisions.
  • Step (F7): Advances exactly one single physics tick (Δt = 1/64 s) to inspect bullet trajectories and collision events.
  • Stop (F8): Resets the scene back to the initial authoring state.

4. Full-Viewport Scripting IDE

When switching to the Scripting IDE workspace, LabEditor replaces the 3D map viewport with a full-screen, distraction-free code editor:

  • Interactive Text Buffer: Multiline typing, cursor navigation, home/end, backspace line merging, Enter key split with auto-indentation.
  • Live Syntax Highlighting: Tokenizer highlighting Lua reserved keywords, numbers, string literals, and engine API identifiers.
  • Direct Disk Roundtrip: Save (Ctrl+S) directly to disk; scripts hot-reload instantly.
  • Protected Bytecode (.luac): Strip symbols and compile to bytecode with a single click for shipping releases.

5. Multi-Genre HUD Canvas Designer

Design user interfaces on a virtual 1920×1080 reference canvas:

  • Genre Presets: Instant templates for FPS, RPG, Racing, and Platformer games.
  • Responsive Anchors: Pin widgets to top-left, center, bottom-right, or full-stretch.
  • Live Lua Scripting: Manipulate elements in real-time via HUD.setText() and HUD.setValue().

6. Universal Hierarchy Search & Undo/Redo

  • Real-Time Search Bar: Instantly filter hundreds of brushes, props, lights, spawns, and UI elements.
  • Command History Stack: Full transactional undo/redo pattern (Ctrl+Z / Ctrl+Y) for brush carving, transforms, and property modifications.

7. Universal One-Click Build & Export

Pressing Ctrl + B opens the Build & Export dialog, enabling export to Windows x64, Linux x64, and WebAssembly (WASM), bundling assets into .labpak archives and preparing standalone shipping packages.

audio.dll (3D Audio & Procedural Synthesizers)

Decoupled Subsystem Architecture: audio.dll is compiled as an independent, portable x64 dynamic link library (DLL) with clean C++20 interfaces. Consumers link against audio.lib and runtime loads audio.dll, ensuring zero build coupling between the engine modules and client games like Frozen-Life (FL).

1. miniaudio v0.11.25 Engine Integration

Engine operates on a dedicated low-latency audio thread with WASAPI / DirectSound backends, dynamic mixing buses, and inverse-square spatial falloff.

// 3D Spatial Sound Emission
Lab::AudioEngine::play3D("rifle_fire", emitterPos, listenerPos, volume);

2. 26 Procedural PCM Synthesizers

Generates gunfire, ricochets, explosions, mechanical reload sounds, footsteps, and UI feedback programmatically without requiring heavy audio asset files on disk.

3. CMake Integration & Compilation

To integrate audio.dll into your game client, level editor, or standalone tool, link against its import library target in CMake:

# Link against audio.dll in CMakeLists.txt
find_package(LabEngine REQUIRED)

target_include_directories(MyTarget PRIVATE
    "${LAB_ENGINE_DIR}/include"
)

target_link_libraries(MyTarget PRIVATE
    audio
)

# Automatically copy audio.dll to the output directory on build
add_custom_command(TARGET MyTarget POST_BUILD
    COMMAND ${CMAKE_COMMAND} -E copy_if_different
    "${LAB_BIN_DIR}/audio.dll"
    "$<TARGET_FILE_DIR:MyTarget>/audio.dll"
)

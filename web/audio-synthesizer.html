1. Audio Engine Architecture

The LabAudio subsystem is designed to operate completely independently of heavy external binary libraries. Instead of requiring gigabytes of recorded audio samples, the engine features a mathematical synthesis layer capable of generating 26 distinct tactical sounds directly in code.

2. miniaudio Backend & Zero-Allocation Mixing

Audio output is driven by miniaudio, configured for low-latency asynchronous callback operation. The engine streams 16-bit signed integer PCM data at 44.1 kHz, maintaining lock-free circular buffers to prevent frame drops.

3. 3D Distance Attenuation & Stereo Panning

Sounds played in 3D space calculate distance attenuation and stereo channel gain relative to the listener camera: 

// 3D Spatial Attenuation Math
Vec3 toSource = soundPos - listenerPos;
float dist = toSource.length();
float gain = 1.0f / (1.0f + 0.12f * std::max(0.0f, dist - 1.5f));

// Stereo panning based on listener right vector
Vec3 dir = toSource.normalized();
float pan = dir.dot(listenerRight); // -1.0 (full left) to +1.0 (full right)
float leftVol = gain * std::clamp(0.5f * (1.0f - pan), 0.0f, 1.0f);
float rightVol = gain * std::clamp(0.5f * (1.0f + pan), 0.0f, 1.0f);

4. 26 Procedural 16-Bit PCM Synthesizers

Lab Engine mathematically synthesizes all combat and environmental sounds in pure C++:

  • M4A4-S Silenced Gunfire: Initial high-frequency impulse burst mixed with decaying white noise and chamber resonance.
  • Railgun Discharge: Hyper-velocity sub-bass sweep (80Hz to 20Hz) combined with electrical plasma crackle.
  • Cryo-Beam Freezing: Resonant white noise modulation with crisp crystal shatter harmonics.
  • Footsteps (Snow & Metal): Low-pass filtered granular crunches varying dynamically based on floor texture tag.
  • Door Hydraulics & Mechanical Clicks: Low-frequency motor hum and metal bolt latching transients.

5. Real-Time RMS Lip-Sync Analysis

In dialogue sequences, spoken audio is analyzed on a 20ms sliding window via Root-Mean-Square (RMS) energy calculation: 

float rms = 0.0f;
for (int i = 0; i < windowSize; ++i) {
    float sample = pcmBuffer[idx + i] / 32768.0f;
    rms += sample * sample;
}
rms = std::sqrt(rms / windowSize);

// Directly drives facial blend shape
jawOpenWeight = std::clamp(rms * 4.5f, 0.0f, 1.0f);

1. Scripting Architecture & Rationale

Hardcoding weapon damages, player walk speeds, jump impulses, and bot reaction intervals into C++ source code leads to long compilation cycles and prevents game designers from tuning feel in real time.

The LabScript subsystem embeds a pure C Lua 5.4 virtual machine directly into the engine, decoupling gameplay tuning completely from core executable compilation.

2. Decoupled Game Balance (scripts/balance.lua)

All gameplay balance parameters are defined in scripts/balance.lua: 

-- scripts/balance.lua
Balance = {
    Player = {
        walkSpeed = 5.5,
        sprintSpeed = 8.5,
        jumpImpulse = 6.2,
        gravity = -18.5,
        maxHealth = 100
    },
    Weapons = {
        M4A4S = { damage = 32.0, rpm = 660, clip = 30, range = 75.0 },
        Shotgun = { pellets = 8, damagePerPellet = 14.0, spread = 0.045 },
        Railgun = { damage = 150.0, cooldown = 1.5, pierceCount = 3 },
        Minigun = { damage = 18.0, rpm = 920, spinUpTime = 0.25 }
    },
    Bots = {
        reactionTime = 0.18,
        headshotMultiplier = 2.5,
        strafingFrequency = 1.2
    }
}

3. Interactive Developer Console (~ Key)

Pressing the Tilde Key (~) drops down the translucent interactive console. Developers can execute arbitrary Lua commands live during gameplay: 

] lab_set_gravity(-9.8)
[Lua] Gravity adjusted to -9.8 m/s^2
] Balance.Player.walkSpeed = 12.0
[Lua] Player walk speed adjusted to 12.0 m/s (Super Sprint)
] lab_spawn_bot("t-800", 0, 2, 5, "Minigun")
[Lua] Spawned T-800 bot with Minigun at (0, 2, 5)

4. C++ / Lua C-API Engine Hooks & Camera Control

The C++ engine registers functions and namespaces into the Lua global environment via lightweight C wrappers. This includes real-time camera switching, HUD bindings, entity scripts, and trigger callbacks: 

-- Camera Object & Scene Control API:
Camera.setActive("cam_tpp")     -- Switch active camera by name
local curCam = Camera.getActive() -- Returns current active camera name ("cam_tpp")
Camera.setFov(85.0)             -- Dynamically adjust field of view
Camera.setPosition(0, 3.5, 10)  -- Reposition camera in 3D scene
Camera.setRotation(0, 180, 0)   -- Set Pitch, Yaw, Roll

-- Lifecycle & Trigger Hooks:
function OnUpdate(dt)
    -- Called every frame tick with delta time
end

function OnTriggerEnter(entityId, otherEntityId)
    -- Called when entity overlap or proximity event occurs (doors, pickups, triggers)
    if otherEntityId == 1 then
        HUD.setText("rpg.quest_status", "ZWOJE 1/5")
    end
end

5. Sandbox Safety & Live Script Reloading

Executing lab_reload_scripts() flushes and re-evaluates all Lua files on the fly. If a script contains syntax errors or infinite loops, the pcall protected environment safely intercepts the error and logs it to the in-engine console without crashing the application.

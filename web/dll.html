Lab SDK Documentation

Welcome to the Lab SDK documentation hub. The Lab Software Development Kit is the modular C++20 application framework used to create 2D and 3D games, custom level geometry, and drop-in extensions around Lab Engine and Frozen-Life.

The engine is architected into 11 decoupled dynamic link libraries (.dll), a multi-workspace visual creation suite (LabEditor, LabHammer, LabStudio, LabHUD), and a sandboxed Lua 5.4 plugin system.

Code and Logic (11 Decoupled Engine DLLs)

Engine.dll

64Hz fixed timestep loop, Win32/GLFW input, SIMD math, and font rasterizer.

render.dll

OpenGL 4.5+ DSA renderer, shadow mapping, and CSG polyhedra clipping.

audio.dll

miniaudio hardware thread, 3D attenuation, and procedural PCM synthesis.

physics.dll

moveAndSlide controller, rigid body props, and slab ray-AABB math.

animation.dll

GPU vertex skinning, cryo-suit FPP arms, and bone matrices.

world.dll

.labmap scene parser, 9-weapon ballistics, and retinal scanners.

network.dll

64-128Hz UDP datagrams, client prediction, and LAN broadcast.

ai.dll

5-state combat FSM, ray-AABB perception, and FBX clip retargeting.

script.dll

Embedded Lua 5.4.6 VM, weapon balance tables, and console hooks.

studio.dll

3D gizmo transforms, reload curve choreography, and blend shapes.

hud.dll

2D hierarchical HUD canvas, RGBA widget rendering, and .labhud serialization.

Native C++ Plugins

Single-file plugins/*.dll addons managed via the in-engine Package Manager.

Subsystem Interface Contracts (server.dll, client.dll, physics.dll)

Lab Engine decouples authoritative simulation, client interpolation, and rigid-body dynamics into isolated subsystem contracts communicated via pure virtual C++20 interfaces:

Subsystem Target Interface Contract Factory Export Primary Responsibilities
server.dll IServerSubsystem CreateServerSubsystem() 64/128Hz authoritative tick simulation, ECS entity lifecycle, delta snapshot encoding, headless server execution.
client.dll IClientSubsystem CreateClientSubsystem() Circular snapshot history buffers, Hermite/slerp state interpolation, local input prediction, reconciliation.
physics.dll IPhysicsSubsystem CreatePhysicsSubsystem() Swept-AABB kinematics, SAT 3D contact manifold solver, raycast suspension vehicles, Archimedes fluid buoyancy.

ABI & LAB_API Export Specification

Every subsystem module uses the unified LAB_API symbol visibility macro across shared library boundaries:

// LabExport.h – Unified Dynamic Link Visibility
#pragma once

#if defined(_WIN32) || defined(__CYGWIN__)
  #if defined(LAB_BUILDING_DLL)
    #define LAB_API __declspec(dllexport)
  #else
    #define LAB_API __declspec(dllimport)
  #endif
#else
  #define LAB_API __attribute__((visibility("default")))
#endif

CMake Integration & Consumer Linking

Executables such as Frozen-Life and LabEditor link against the modular DLL targets via CMake:

target_link_libraries(FrozenLife PRIVATE
    Engine render audio physics animation
    world network ai script studio hud
)

Subsystem Initialization & Loading Order

  1. Engine.dll: Initialize window context, Win32/GLFW event dispatch, and 64Hz clock accumulator.
  2. render.dll: Query OpenGL 4.5+ DSA profile, allocate shadow framebuffers, and compile GLSL shaders.
  3. audio.dll: Start dedicated miniaudio hardware thread and initialize 26 procedural PCM synthesizers.
  4. physics.dll: Initialize spatial broadphase grids and swept-AABB kinematic constraints.
  5. animation.dll: Load glTF 2.0 humanoid rig, binary .anim cache, and FPP viewmodel arms.
  6. script.dll: Open Lua 5.4 virtual machine, load game_mechanics.lua, and scan drop-in plugins.
  7. world.dll: Parse .labmap geometry, spawn weapon entities, and attach hud.dll.
  8. ai.dll & network.dll: Spawn tactical bots and bind authoritative UDP sockets.

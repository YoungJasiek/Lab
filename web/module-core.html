Application Lifecycle & Fixed Timestep Loop

The Lab::Engine class encapsulates the master execution loop, providing deterministic fixed-timestep physics updates (64Hz) decoupled from uncapped rendering framerates. Time accumulation prevents temporal aliasing while maintaining sub-millisecond precision.

// Initialize Engine Context
Lab::Engine engine("Lab Showcase", 1920, 1080);
engine.run(); // Starts fixed-timestep accumulator loop

Input System (Win32 & GLFW)

Lab::Input delivers zero-latency polling for keyboard keys (512-code array), mouse buttons (8 channels), cursor coordinates, and fractional delta vectors with smoothing filter.

if (Lab::Input::isKeyDown(GLFW_KEY_W)) {
    playerPos += camera.getFront() * moveSpeed * dt;
}
Lab::Vec2 mouseDelta = Lab::Input::getMouseDelta();

Linear Algebra & Camera Transforms

Optimized 3D mathematics suite including Vec2, Vec3, and Mat4 with SIMD-aligned structures, quaternion SLERP interpolation, and Lab::Camera perspective and view matrix evaluation.

Font Atlas & Rasterizer

Lab::LabFont builds crisp, anti-aliased texture atlases using Windows native GDI font rasterization (Segoe UI, Arial) and the bundled Geo Sans Light typeface with sub-pixel rendering.

CMake Integration & Compilation

To integrate LabCore.dll in your game or tool, include its headers and link to its import library:

target_include_directories(MyGame PRIVATE "${LAB_ENGINE_DIR}/include")
target_link_libraries(MyGame PRIVATE LabCore)

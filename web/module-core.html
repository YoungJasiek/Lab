Decoupled Subsystem Architecture: Engine.dll is compiled as an independent, portable x64 dynamic link library (DLL) with clean C++20 interfaces. Consumers link against Engine.lib and runtime loads Engine.dll, ensuring zero build coupling between the engine modules and client games like Frozen-Life (FL).

1. Application Lifecycle & Fixed Timestep Loop

The Lab::Engine class encapsulates the master execution loop, providing deterministic fixed-timestep physics updates (64Hz) decoupled from uncapped rendering framerates. Time accumulation prevents temporal aliasing while maintaining sub-millisecond precision.

// Initialize Engine Context with strict RAII
Lab::Engine engine("Lab Showcase", 1920, 1080);
engine.run(); // Starts fixed-timestep accumulator loop at 64Hz

The loop guarantees that every physics and logic update receives a constant delta time (dt = 1/64s ≈ 15.625ms), eliminating non-deterministic physics anomalies across different display refresh rates (60Hz, 144Hz, 240Hz).

2. Input System (Win32 & GLFW)

Lab::Input delivers zero-latency polling for keyboard keys (512-code array), mouse buttons (8 channels), cursor coordinates, and fractional delta vectors with smoothing filter.

if (Lab::Input::isKeyDown(GLFW_KEY_W)) {
    playerPos += camera.getFront() * moveSpeed * dt;
}
Lab::Vec2 mouseDelta = Lab::Input::getMouseDelta();
camera.processMouseMovement(mouseDelta.x, mouseDelta.y);

Coordinates are normalized against high-DPI scaling factors via native Win32 GetCursorPos and GLFW callback multiplexing, preventing cursor drops across DLL process boundaries.

3. Linear Algebra & Camera Transforms

Optimized 3D mathematics suite including Vec2, Vec3, and Mat4 with SIMD-aligned structures, quaternion SLERP interpolation, and Lab::Camera perspective and view matrix evaluation.

Matrix operations adhere strictly to OpenGL column-major memory layout, facilitating direct uploads to GPU uniform buffers and shader push constants without transposition.

4. Font Atlas & Rasterizer

Lab::LabFont builds crisp, anti-aliased texture atlases using Windows native GDI font rasterization (Segoe UI, Arial) and the bundled Geo Sans Light typeface with sub-pixel rendering.

Glyph metric caches (advance width, bearing, kerning pairs) ensure instantaneous UI text rendering without runtime CPU string rasterization.

5. CMake Integration & Compilation

To integrate Engine.dll into your game client, level editor, or standalone tool, link against its import library target in CMake:

# Link against Engine.dll in CMakeLists.txt
find_package(LabEngine REQUIRED)

target_include_directories(MyTarget PRIVATE
    "${LAB_ENGINE_DIR}/include"
)

target_link_libraries(MyTarget PRIVATE
    Engine
)

# Automatically copy Engine.dll to the output directory on build
add_custom_command(TARGET MyTarget POST_BUILD
    COMMAND ${CMAKE_COMMAND} -E copy_if_different
    "${LAB_BIN_DIR}/Engine.dll"
    "$<TARGET_FILE_DIR:MyTarget>/Engine.dll"
)

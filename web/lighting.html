Production Feature: Dynamic multi-light illumination is integrated natively across render.dll, world.dll, and LabHammer. Brushes and prop meshes in the level editor update instantaneously when lamps are moved, raised, or configured.

1. System Overview

The Lab Engine Dynamic Lighting Pipeline brings high-fidelity local illumination to indoor facility corridors, subterranean caverns, and combat arenas in Frozen-Life. Built directly into render.dll, the lighting model combines global directional sun illumination with dynamic point lights (lamps, emergency beacons, flares, reactor cores) and tactical weapon flashlights.

Key highlights of the architecture:

  • Forward Multi-Light Acceleration: Single-pass fragment shader evaluates up to 16 concurrent point lights per draw call with near-zero overhead when light count is zero.
  • Physically-Plausible Attenuation: Distance falloff accurately follows the inverse-square law with standard linear and quadratic coefficients tuned for crisp indoor contrast.
  • Smooth Horizon Windowing: Lights gracefully fade to zero intensity at their bounding radius R, eliminating hard polygon edge cuts.
  • Real-Time Editor Viewport Preview: Level designers in LabHammer see exact lighting as players will experience in-game.

2. Mathematical Model & Attenuation

For each active point light i at position PL with color CL, intensity IL, and radius RL, the surface illumination at point PS with normal N and view direction V is governed by:

// 1. Direction and Distance
vec3 lightDir = normalize(lightPos - FragPos);
float dist = length(lightPos - FragPos);

// 2. Quadratic Distance Falloff (Inverse-Square approximation)
float attenuation = 1.0 / (1.0 + 0.09 * dist + 0.032 * dist * dist);

// 3. Smooth Radius Windowing Cutoff
float cutoff = clamp(1.0 - (dist / lightRadius), 0.0, 1.0);
cutoff = cutoff * cutoff; // Smooth Hermite falloff
attenuation *= cutoff;

// 4. Diffuse Lambertian Term
float diff = max(dot(norm, lightDir), 0.0);

// 5. Blinn-Phong Halfway Specular Term
vec3 halfwayDir = normalize(lightDir + viewDir);
float spec = pow(max(dot(norm, halfwayDir), 0.0), 32.0);

// 6. Cumulative Point Radiance
vec3 lightContrib = (lightColor * diff * 0.9 + vec3(1.0) * spec * 0.4) * lightIntensity * attenuation;

3. GLSL Forward Shading Implementation

The standard fragment shader receives uniforms through Direct State Access (DSA) in a compact, cache-friendly uniform array:

#define MAX_POINT_LIGHTS 16

struct PointLightShader {
    vec3 position;
    float intensity;
    vec3 color;
    float radius;
};

uniform int uNumPointLights;
uniform PointLightShader uPointLights[MAX_POINT_LIGHTS];

void main() {
    // ... Directional and ambient base pass ...
    vec3 pointLightsResult = vec3(0.0);
    for (int i = 0; i < uNumPointLights && i < MAX_POINT_LIGHTS; ++i) {
        vec3 lDir = normalize(uPointLights[i].position - FragPos);
        float d = length(uPointLights[i].position - FragPos);
        if (d >= uPointLights[i].radius) continue;

        float att = 1.0 / (1.0 + 0.09 * d + 0.032 * d * d);
        float win = clamp(1.0 - (d / uPointLights[i].radius), 0.0, 1.0);
        att *= (win * win);

        float dCoeff = max(dot(norm, lDir), 0.0);
        vec3 hDir = normalize(lDir + viewDir);
        float sCoeff = pow(max(dot(norm, hDir), 0.0), 32.0);

        pointLightsResult += (uPointLights[i].color * dCoeff * 0.9 + vec3(1.0) * sCoeff * 0.35) 
                             * uPointLights[i].intensity * att;
    }
    vec3 finalColor = (baseLighting + pointLightsResult) * surfaceColor;
    FragColor = vec4(finalColor, 1.0);
}

4. LabHammer Lamp Placement Tool

In LabHammer, lamps are first-class entities selectable from the left toolbar via Tool [7] - Lamp Tool:

Tool [7] Toolbar Quick Select
3D Bulb Glowing Core & Fixture
Wire Radius Visual Bounding Sphere
3D Gizmo Interactive Elevation Arrow

Interactive Viewport Controls

  • Placement: Press 7 or click the Lamp icon in the left toolbar. Left-click in the 3D viewport or press E to spawn a lamp at the 3D cursor position.
  • Selection: Click directly on the glowing bulb or select [LIGHT #X] from the Struktura (Outliner) sidebar tab.
  • Elevation (+Y): Use the vertical green gizmo arrow, press R / C, scroll the mouse wheel, or click [^ UP (+Y)] / [v DOWN (-Y)] in the Properties tab.
  • Duplication: Press Ctrl+D or click Duplicate in the Outliner to clone the lamp with grid snap offset.

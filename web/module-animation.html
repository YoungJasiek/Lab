LabAnimation.dll

Animation Pipeline C++20 OpenGL 4.5+ DSA x64 Dynamic Library
Module: LabAnimation.dll
Target NameLabAnimation.dll
Output TypeShared Library (.dll + .lib)
HeadersLabAnim.h, LabArms.h
StandardISO C++20 / MSVC v143
Standalone RepoDesktop/lab-animation

High-performance skeletal animation engine supporting glTF 2.0 / GLB keyframes, quaternion SLERP interpolation, bone matrices evaluation, and articulated cryo-suit FPP arms with telemetry LEDs.

Table of Contents
  1. Skeletal Animation Pipeline
  2. Tactical FPP Viewmodel Arms

Skeletal Animation Pipeline

35-bone humanoid skeleton deformation, cross-fade animation clip blending, and dynamic bone socket binding for weapon attachments.

Tactical FPP Viewmodel Arms

Articulated cryo-suit gauntlet model with dual-socket hand grips, spring-damper recoil, walking roll sway, and tactical inspect.

CMake Integration & Compilation

To integrate LabAnimation.dll in your game or tool, include its headers and link to its import library:

target_include_directories(MyGame PRIVATE "${LAB_ENGINE_DIR}/include")
target_link_libraries(MyGame PRIVATE LabAnimation)

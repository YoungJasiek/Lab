LabHUDEditorCore (LabHUDEditorCore.dll)

Module: modules/lab-hud Binary: LabHUDEditorCore.dll Standard: Modern C++20 Exported Header: LabHUDEditor.h

1. Subsystem Architecture & Responsibilities

LabHUDEditorCore.dll provides the complete backend for the 2D layout editor, handling:

  • Hierarchical Element Graph: Responsive anchor positioning, nesting, Z-ordering, and transformations.
  • Widget Type Pipeline: Primitive rects, cards, panels, buttons, dynamic health/progress bars, ammo counters, and custom image sprites.
  • Alpha Channel Blending: Full RGBA transparency pipeline for background cards, textures, and borders.
  • Lua 5.4 Logic Bindings: Storage, execution, and serialization of runtime event hooks and game variable bindings.
  • File I/O Serialization: Native parsing and saving of .labhud format.

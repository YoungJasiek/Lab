Help Reference & Guidelines

This section provides detailed reference documentation for contributing to the wiki without dead links:

Etiquette & Contribution Standards

Always assume good faith when collaborating on wiki articles. Avoid edit wars; if you disagree with an edit, take the discussion to the corresponding Talk page. When documenting engine subsystems, prioritize factual C++20 specifications, header declarations, and benchmarked metrics over subjective impressions.

Policies and Guidelines

All documentation must accurately describe working features in the active repository. Subsystems must be cross-linked to their respective header files in include/. Avoid modern SaaS clutter or emoji icons; maintain the crisp, technical 2007 encyclopedic style.

Style Guide & Code Formatting

Format C++20 code blocks using <pre> tags with tab indentation. Highlight keywords in #ff1f71, classes in #0082ff, and constants in #b5b5b5. Use <code> for inline symbols such as Vec3, IServerSubsystem, or .labscene.

Page Creation & Naming Conventions

Name module pages using lowercase hyphenated filenames (e.g., module-physics.html, weapons-viewmodel.html). Every new article should feature the top 2007 header, MediaWiki namespace tabs, left sidebar navigation, and bottom Navbox matrix.

Linking & Anchor Conventions

Never use raw placeholder hashes (#) that cause dead jumps. Always pair internal section jumps with explicit IDs (e.g., href="modules.html#sec-source-arch"). When referencing external tools or repositories, specify target="_blank".

Table of Contents (TOC) Syntax

The __TOC__ magic word generates a structured table of contents. In static HTML, wrap the TOC in a <div class="toc"> with <span class="tocnumber"> and <span class="toctext"> for faithful 2007 MediaWiki numbering.

Deletion & Deprecation Process

When an API or subsystem is deprecated (e.g., migrating legacy .labmap to JSON .labscene), do not delete the page abruptly. Document the migration path, provide backward compatibility instructions, and add a warning banner directing readers to the updated specification.

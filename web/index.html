Welcome to the Lab Developer Community

The comprehensive engineering knowledge base and reference wiki for Lab Engine, the standalone 3D level editor LabHammer, and the official First Playable Test Build of Frozen-Life (FL). Engineered from scratch in modern C++20, featuring an OpenGL 4.5+ Direct State Access (DSA) rendering pipeline, strict RAII memory management with zero raw pointers, branchless ray-AABB physics, and native real-time level authoring tools.

Game: Lab.exe (Frozen-Life FPS) Editor: LabHammer.exe (3D CAD Suite) Language: ISO C++20 / C++23 Renderer: OpenGL 4.5+ DSA Format: .labmap (Plain-Text) Discipline: 100% RAII • Zero Raw Pointers

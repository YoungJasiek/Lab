Sign up to become part of the community!

Whether you're building a commercial project or a Lab engine modification, you'll want to sign up as a Lab developer today. It's free to join and is open to anyone working with the Lab engine and its software development kit.

λ Lab Engine and the Modular SDK »

If you want to create games with the core engine, inspect Source-modular DLL subsystems (server.dll, client.dll, physics.dll), implement OpenGL 4.5+ Direct State Access (DSA) renderers, or explore C++20 low-level architecture, click above.

⚒ LabHammer and the Editor Suite »

If you want to author 3D maps, create CSG brush geometry, place entities, configure dynamic lamps and lighting, or use the multi-workspace LabEditor suite (3D Level, 2D Tilemap, Studio Poser, HUD Designer), click above.

FL Frozen-Life Documentation »

If you want to explore the flagship tactical FPS demonstration game built on the Lab SDK, test playable maps (Cryo & Alpha), inspect weapon ballistics, 64-128Hz multiplayer, or write mods, click above.

lab)

The high-performance C++20 engine under the hood. Modular DLL subsystems, OpenGL 4.5+ DSA, and zero dynamic allocation frame loop so your team can focus on gameplay.

hammer)

Multi-workspace 3D CAD level editor featuring CSG brush geometry, 2D quad-viewports, dynamic lamps, and native .labscene scene graph.

❄FL-SDK

The premier tactical FPS showcase demonstration built on the Lab SDK with viewmodel ballistics, combat bots, and 64-128Hz UDP client-predicted multiplayer.

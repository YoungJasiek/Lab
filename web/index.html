From Lab Developer Community – The Official Technical Wiki for Lab Engine, LabHammer & Frozen-Life

Welcome to the Lab Developer Community

The comprehensive engineering knowledge base and reference wiki for Lab Engine – a high-performance, modular C++20 & OpenGL 4.5+ Direct State Access (DSA) 3D Game Engine designed for building tactical FPS games, simulation software, and CAD tools. Frozen-Life (FL) is the flagship playable demonstration game powered by the Lab Engine.

Engine: Lab SDK (11 Modular DLLs) Demo Game: FrozenLife.exe Editor: LabHammer.exe Studio: LabStudio.exe HUD Editor: LabHUD.exe Language: ISO C++20 / C++23 Renderer: OpenGL 4.5+ DSA Network: Authoritative UDP (64-128Hz) Scripting: Lua 5.4

Decoupled Dynamic Link Library (DLL) Ecosystem

Lab is architected into 10 decoupled, high-performance dynamic link libraries (.dll). Each module maintains an independent repository, public C++20 headers in include/, and a dedicated CMake build pipeline:

⚙

LabCore.dll

Engine lifecycle, deterministic 64Hz loop timing, Win32/GLFW input system, linear algebra (Vec2, Vec3, Mat4), camera transforms, and font rendering.

  • • Fixed Timestep Loop
  • • Input Polling & Smoothing
  • • Vector & Matrix Math
🎨

LabRender.dll

OpenGL 4.5+ Direct State Access (DSA), Blinn-Phong lighting, CSG brush clipping, projective impact decals, post-processing, and skeletal animation rendering.

  • • DSA Architecture
  • • Shadow Mapping & Spotlights
  • • CSG Brush Clipping
🔊

LabAudio.dll

Low-latency 3D spatial audio system with miniaudio integration and 26 built-in procedural 16-bit PCM sound synthesizers.

  • • miniaudio Threading Backend
  • • Procedural Sound Synthesizers
⚖

LabPhysics.dll

Deterministic 3D physics with swept-AABB collision detection, kinematic moveAndSlide character controller, rigid bodies, and slab raycasting.

  • • moveAndSlide Controller
  • • Rigid Body Dynamics
  • • Slab Ray-AABB Math
🤖

LabAnimation.dll

Skeletal keyframe animation blending, glTF 2.0 / GLB loader, quaternion SLERP interpolation, and articulated cryo-suit FPP arms with telemetry LEDs.

  • • Skeletal GPU Skinning
  • • Tactical FPP Arms Viewmodel
🌎

LabWorld.dll

Map environment management (.labmap), 9-weapon arsenal mechanics, particle emitters, biometric retinal terminals, session state, and HUD overlay.

  • • .labmap Map Specification
  • • 9-Weapon Ballistics
  • • Biometric Retinal Terminals
📶

LabNetwork.dll

Ultra-low latency UDP client-server networking (64-128Hz), client prediction, server reconciliation, ServerBrowser LAN discovery, and multiplayer chat.

  • • Prediction & Reconciliation
  • • Binary UDP Protocol
  • • LAN Server Discovery
🚀

LabAI.dll

Autonomous CombatBot sensory perception (LOS raycasting), behavioral finite state machine, FBX Mixamo skeletal retargeting, and dynamic weapon tactics.

  • • Behavioral Finite State Machine
  • • FBX Mixamo Retargeting
📜

LabScript.dll

Embedded Lua 5.4 scripting engine integrating hot-reloadable gameplay mechanics, weapon balistics, map events, and console commands.

  • • Lua 5.4 Integration
  • • game_mechanics.lua Balance
🎭

LabStudioCore.dll

Character & Weapon Studio engine backend for weapon socket calibration, reload choreography curve editing, and facial phoneme lip-sync.

  • • Dual-Socket Weapon Grips
  • • Reload Curve Choreography
  • • Facial Blend Shapes & Lip-Sync

1. Direct State Access (DSA) Architecture

Direct State Access eliminates global OpenGL state binding. Vertex arrays, framebuffers, and textures are configured in-place without altering context state machine bindings.

// DSA Buffer and VAO allocation
glCreateVertexArrays(1, &_vao);
glCreateBuffers(1, &_vbo);
glNamedBufferStorage(_vbo, size, data, GL_DYNAMIC_STORAGE_BIT);
glVertexArrayVertexBuffer(_vao, 0, _vbo, 0, sizeof(Vertex));

2. Directional, Point & Spot Lighting

Blinn-Phong illumination with Source Engine-like contrast. Features 2048x2048 cascaded shadow maps, 3x3 PCF filtering, and tactical flashlight spotlights.

3. Constructive Solid Geometry (CSG)

Real-time Sutherland-Hodgman convex polyhedron polygon clipping supporting Carve, Clip, Hollow, Union, and Intersection operations for Valve Hammer styled map brushes.

4. Post-Processing & Atmosphere

Full-screen HDR tone mapping, subtle bloom, cryo frost vignetting, and color correction passes with zero latency.

5. CMake Integration & Compilation

To integrate LabRender.dll into your game client, level editor, or standalone tool, link against its import library target in CMake:

# Link against LabRender.dll in CMakeLists.txt
find_package(LabEngine REQUIRED)

target_include_directories(MyTarget PRIVATE
    "${LAB_ENGINE_DIR}/include"
)

target_link_libraries(MyTarget PRIVATE
    LabRender
)

# Automatically copy LabRender.dll to the output directory on build
add_custom_command(TARGET MyTarget POST_BUILD
    COMMAND ${CMAKE_COMMAND} -E copy_if_different
    "${LAB_BIN_DIR}/LabRender.dll"
    "$<TARGET_FILE_DIR:MyTarget>/LabRender.dll"
)

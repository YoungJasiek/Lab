Decoupled Subsystem Architecture: render.dll is compiled as an independent, portable x64 dynamic link library (DLL) with clean C++20 interfaces. Consumers link against render.lib and runtime loads render.dll, ensuring zero build coupling between the engine modules and client games like Frozen-Life (FL).

1. Direct State Access (DSA) Architecture

Direct State Access eliminates global OpenGL state binding. Vertex arrays, framebuffers, and textures are configured in-place without altering context state machine bindings.

// DSA Buffer and VAO allocation
glCreateVertexArrays(1, &_vao);
glCreateBuffers(1, &_vbo);
glNamedBufferStorage(_vbo, size, data, GL_DYNAMIC_STORAGE_BIT);
glVertexArrayVertexBuffer(_vao, 0, _vbo, 0, sizeof(Vertex));

2. Directional, Point & Spot Lighting

Blinn-Phong illumination with Source Engine-like contrast. Features 2048x2048 cascaded shadow maps, 3x3 PCF filtering, tactical flashlight spotlights, and Multi-Light Dynamic Forward Shading supporting up to 16 point light lamps per scene with realistic quadratic distance attenuation (\(1 / (1 + 0.09d + 0.032d^2)\)) and smooth horizon radius cutoff.

Dynamic lamps are natively supported in LabHammer via the Lamp Tool [7] with 3D glowing bulb visualization, radius wireframe sphere, interactive +Y elevation gizmo, and Kelvin/Atmosphere color presets. See full technical details in the Advanced Dynamic Lighting & Lamp System Documentation.

3. Constructive Solid Geometry (CSG)

Real-time Sutherland-Hodgman convex polyhedron polygon clipping supporting Carve, Clip, Hollow, Union, and Intersection operations for LabHammer styled map brushes.

4. Post-Processing & Atmosphere

Full-screen HDR tone mapping, subtle bloom, cryo frost vignetting, and color correction passes with zero latency.

5. CMake Integration & Compilation

To integrate render.dll into your game client, level editor, or standalone tool, link against its import library target in CMake:

# Link against render.dll in CMakeLists.txt
find_package(LabEngine REQUIRED)

target_include_directories(MyTarget PRIVATE
    "${LAB_ENGINE_DIR}/include"
)

target_link_libraries(MyTarget PRIVATE
    render
)

# Automatically copy render.dll to the output directory on build
add_custom_command(TARGET MyTarget POST_BUILD
    COMMAND ${CMAKE_COMMAND} -E copy_if_different
    "${LAB_BIN_DIR}/render.dll"
    "$<TARGET_FILE_DIR:MyTarget>/render.dll"
)
